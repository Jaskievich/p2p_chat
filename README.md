Краткое описание
Это веб-приложение для видеозвонков и текстового чата между двумя пользователями (P2P) прямо в браузере. Программа позволяет двум людям общаться через интернет, используя видеокамеру, микрофон и текстовые сообщения, без необходимости устанавливать дополнительное ПО или регистрироваться.

Основные возможности
🎥 Видеосвязь в реальном времени
Пользователь видит своё изображение (с камеры) и изображение собеседника одновременно.

Соединение устанавливается напрямую между двумя браузерами (технология WebRTC — Peer-to-Peer), что снижает задержку и нагрузку на серверы.

💬 Встроенный текстовый чат
Во время звонка можно обмениваться текстовыми сообщениями через отдельный канал связи (WebRTC Data Channel).

Сообщения отправляются мгновенно.

🚀 Создание комнаты
Один пользователь нажимает «Создать комнату» — программа генерирует уникальный короткий код (например, A3F9K2).

Этот код нужно передать собеседнику любым удобным способом (мессенджер, SMS, голосом).

Код можно скопировать в один клик кнопкой «📋 Копировать».

🔗 Подключение к комнате
Второй пользователь вводит полученный код в поле и нажимает «Подключиться».

Соединение устанавливается автоматически — после этого оба видят и слышат друг друга.

🎙️ Управление устройствами
Во время звонка доступны кнопки:

Выкл/вкл микрофон — временно отключить звук.

Выкл/вкл камеру — временно скрыть своё видео.

📊 Индикация состояния
Внизу экрана отображается строка статуса, которая сообщает:

ожидание подключения,

установлено ли P2P-соединение,

возникающие ошибки (нет доступа к камере, проблемы с сетью и т. д.).

В чате также появляются системные уведомления о ходе подключения.

Как это работает (для пользователя)
Открыть страницу в браузере (Chrome, Firefox, Edge, Safari).

Разрешить доступ к камере и микрофону по запросу браузера.

Создать комнату или ввести код существующей.

Передать код собеседнику и дождаться его подключения.

Общаться — по видео, голосу и в чате.

Технические особенности (без углубления в детали)
Соединение устанавливается напрямую между браузерами (P2P), что обеспечивает быструю передачу видео и звука.

Для «знакомства» браузеров друг с другом используется MQTT-брокер (broker.emqx.io) — он лишь помогает обменяться техническими данными, сам видео/аудио не передаёт.

Применяются STUN/TURN-серверы — они нужны, чтобы соединение работало даже через сложные сети (например, мобильный интернет, корпоративные сети, NAT).

Работает на любых устройствах — ПК, ноутбуки, планшеты, смартфоны (адаптивная вёрстка).

Кому подойдёт
✅ Для быстрых видеозвонков без регистрации.

✅ Для тестирования WebRTC-технологий.

✅ Как простой способ связаться с одним человеком, когда мессенджеры недоступны.

✅ Для демонстрации P2P-связи в учебных целях.

Ограничения
⚠️ Рассчитано только на двух участников (один создаёт, другой подключается).

⚠️ Используется публичный MQTT-брокер — не предназначено для конфиденциальных разговоров.

⚠️ Для стабильной работы в сложных сетях желателен свой TURN-сервер (в коде указан только публичный).

⚠️ Требуется HTTPS (или localhost) для работы доступа к камере/микрофону в современных браузерах.
